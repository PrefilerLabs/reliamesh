# ReliaMesh brand mark

The interlocking mint R/M symbol represents connected, dependable agent infrastructure.
The navy tile keeps the mark readable against both light and dark browser chrome.
The website pairs it with a text wordmark so the name remains crisp and accessible.

- `reliamesh-mark-master.png`: original generated raster master, with transparent corners.
- `../../src/reliamesh/static/reliamesh-mark.png`: 256px website export.
- `../../src/reliamesh/static/favicon-32.png`: 32px PNG favicon.
- `../../src/reliamesh/static/favicon.ico`: 16px, 32px and 48px favicon frames.
- `../../src/reliamesh/static/apple-touch-icon.png`: 180px touch icon.

Palette: mint `#7EDCBD`, navy `#101B24`, off-white wordmark `#EAF0F3`.
Keep the mark's aspect ratio, colors and internal spacing intact. Exports trim only
transparent outer padding and resample the original artwork. No font download,
analytics or external asset service is needed.

Created for Prefiler Labs Private Limited using the built-in image-generation tool.
The exact generation prompt is recorded in `generation-prompt.txt`.
